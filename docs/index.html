Ollama MySQL MCP Chatbot

A small local AI lab that connects Ollama, MySQL, mysql-mcp-server, and a Flask chatbot.

Ollama MySQL MCP Server Flask Local AI

This project demonstrates how a local language model can generate SQL, send it through a read-only MySQL MCP API, and return a short answer through a simple IRC-style web chatbot.

View on GitHub How it works

How it works

1. User asks

The user asks a database question in the Flask chatbot.

2. Context is loaded

The app loads prompt files and business context from Markdown files.

3. Ollama generates SQL

A local Ollama model generates SQL based on schema and context.

4. MCP runs query

The SQL query is sent to mysql-mcp-server over HTTP.

Python dependencies are defined in requirements.txt. The project currently uses Flask for the web UI and Requests for HTTP calls.

Security notes

  • Use a read-only MySQL user.
  • Do not commit database passwords.
  • Do not expose mysql-mcp-server directly to the internet.
  • Use query timeout and row limits on the MCP server side.
