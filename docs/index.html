Ollama MySQL MCP Chatbot

A small local AI lab that connects Ollama, a MySQL MCP server, and a Flask chatbot to ask natural language questions over a MySQL database.

Ollama MySQL MCP Server Flask Local AI

The project demonstrates how a local language model can generate SQL, send it through a read-only MySQL MCP API, and return a short answer through a simple web chatbot.

View on GitHub How it works

How it works

1. User asks

The user asks a question in the Flask chatbot, such as Who bought Wireless Mouse?

2. Context is loaded

The app loads prompt files and business context from Markdown files.

3. Ollama generates SQL

A local Ollama model generates a safe SQL query based on schema and context.

4. MCP runs query

The query is sent to mysql-mcp-server, which talks to MySQL using a read-only user.

What this project shows

  • How to use Ollama as a local LLM for SQL generation.
  • How to expose MySQL safely through an MCP server.
  • How Markdown context files can explain business meaning to the model.
  • How a small Flask UI can turn the flow into a chatbot.

Security notes

The project is designed for a local lab environment. MySQL should be accessed with a read-only user. Secrets such as database passwords should not be committed to GitHub.
